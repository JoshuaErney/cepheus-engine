# Found Issues (Playtest Log)

A running log of issues found while actually playing the system, kept separate from
`PROJECT_STATUS.md` (which is the curated "what's built" reference, not a place for
raw in-progress notes). Copy the template below for each new issue. Order doesn't
matter — newest on top or bottom, whatever's easiest while you're mid-session.

Once an issue is actually fixed, either delete its entry or flip its status to ✅ and
leave it as a record — your call. If it turns into real code work, it's worth folding
a summary into `PROJECT_STATUS.md`/`CHANGELOG.md` at that point, same as everything
else this session.
